# physchem-interactives
Interactive visualisations and learning tools for physical chemistry, supporting Moodle teaching across gases, thermodynamics, kinetics, equilibria and electrochemistry.

## About

This is a static site built with plain HTML, CSS and JavaScript only — no frameworks, build systems, backends, logins, analytics or databases. It can be hosted directly on GitHub Pages.

## Structure

```
index.html                                   Catalogue of all activities
assets/css/site.css                          Shared stylesheet
gases/maxwell-boltzmann/index.html           Maxwell–Boltzmann distribution
gases/gas-laws/index.html                    Gas laws
gases/real-gases/index.html                  Real gases (van der Waals)
thermodynamics/enthalpy-entropy/index.html   Enthalpy & entropy
thermodynamics/gibbs-energy/index.html       Gibbs energy
kinetics/rate-laws/index.html                Rate laws
kinetics/arrhenius/index.html                Arrhenius equation
equilibria/le-chatelier/index.html           Le Chatelier's principle
electrochemistry/nernst-equation/index.html  Nernst equation
```

## Development

Open `index.html` in a browser, or serve the repository root with any static file server (e.g. `python3 -m http.server`).
